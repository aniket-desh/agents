# Legacy pod bootstrap

This file is retained for the old pod-local `setup.sh` path. For the persistent
CPU-host workflow, run the repository's `install.sh`; it installs the shared
research profile and skills without replacing personal instructions.

For research code, make the smallest transparent change that answers the current
question. Preserve mathematical conventions and validate likely errors with a
tiny exact reference, invariant, analytical limit, or targeted reproduction.
Reuse relevant tests; one-off checks can remain inline. Do not create broad
smoke-test suites, a framework, or a review pipeline for a routine edit.

Negative and inconclusive experimental results are valid. Preserve numerical
outputs, plotting code, source provenance, parameters, and relevant seeds for
reported experiments. Do not automatically pull, commit, or push on startup.

This legacy bootstrap does not install a budget controller or guarantee
unattended continuation. Never infer authority to rent GPUs from this file.
Follow the user's compute limits and protect credentials. Stop and retain pods;
termination remains a human action.
